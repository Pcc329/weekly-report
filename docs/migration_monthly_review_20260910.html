移轉滿月重點盤點

Airtable → Supabase 切換滿一個月・資料庫升級系列第 6 篇

2026-09-10 · 嘉華 Patrick

一、移轉觀察期進度

  • 2026/8/12 完成 Airtable → Supabase 正式切換，Supabase 現為 production 資料庫。
  • 觀察期至 2026/11/12（共三個月），目前已滿一個月，運作穩定，無異常。
  • 目前資料量：Solutions 2,487 筆、Companies 930 家、Cases 115 筆、Program_Promotions 16 筆。

二、備份可靠性驗證

  • 每週五定期執行 pg_dump 備份（Supabase pooler endpoint，PostgreSQL 17 client），備份存放於 OneDrive。
  • 2026/9/10 完成本季度還原驗證演練：於獨立測試環境中完整還原備份檔案，逐表比對筆數，結果完全一致。

三、資料品質稽核與清理成果

資料新鮮度稽核（海巡）

  • 臺灣雲市集（tcloud.gov.tw）：平台已確認停止服務，153 筆高信心度標記下架，1,069 筆疑似下架（政策推論，未逐筆驗證）。
  • 商業服務業專區（商業署）：117 筆與官方公告完整比對，無需變更。
  • 雲市集工業館：329 筆中 139 筆標記疑似下架，修復 4 筆公司關聯連結。

異常方案複查（2026/9/10）

  • 完成一輪針對 26 筆異常方案的資料健康度複查，依情況分類處理（維持下架／確認公司關聯狀態）。
  • 新增 solution_reviews 資料表，記錄每一次複查的時間、觸發原因與判斷結果，避免未來複查覆蓋歷史軌跡。

四、安全稽核進度

已完成（PR #144–#146）

  • AI 生成內容的 XSS 防護（DOMPurify）。
  • 搜尋引擎索引限制（robots.txt + noindex）。
  • API 層級的 IP 限流保護。
  • 資料最小化修正：公司詳情 API 避免曝露聯絡人 email、手機等敏感資訊。

待處理

API 身分驗證（Security Layer 1）為目前優先度最高之未解決項目，自 7/13 起列管，尚待排入時程規劃。

五、下一步

  • 觀察期持續至 11/12，期間持續監控系統穩定性。
  • target_scale 欄位格式標準化（長期功能之前置作業）。
  • CSP 第二波：待 CDN 白名單盤點完成後執行。
  • API 身分驗證架構規劃：待排入時程。
