## 三、領域篩選修正（PR #306、#307）

1. **原因**：7 月遷移時「領域」欄位僅約 5% 有資料，決定不搬；網站的領域篩選仍讀該欄位，自 8/12 起全部排除
2. **修正**：改以方案名稱、適用產業、描述、功能等欄位比對領域詞彙（例：製造業比對「製造、工廠、產線、MES」等）

| 領域 | 修正前 | 修正後 |
|---|---:|---:|
| 旅宿觀光 | 0 | 444 |
| 製造業 | 0 | 453 |
| 醫療照護 | 0 | 238 |
| 建築營造 | 0 | 86 |
| 文化創意 | 0 | 207 |

3. **AI 搜尋**：「製造業有哪些品質管理方案」0 → 8 筆
4. **排序**：選了領域時，適用產業明列該領域的方案排前面（筆數不變）
5. **觀察**：旅宿、文創約九成方案的適用產業都有明列，通用方案列舉的產業多，排序區隔有限，列入後續精準度調整
