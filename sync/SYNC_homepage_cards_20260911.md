## 依使用者確認調整原規格

實際 status.md 位於根目錄，待追蹤事項是「項目／對象／預計時間／狀態」四欄，共 23 筆，沒有優先度或分類。使用者已確認先顯示前 5 筆，其餘 18 筆收合，不要求修改來源格式。

## 函式與解析
- cardText / cardEscape：保留連結標籤、去除粗體與反引號標記，再進行 HTML 特殊字元轉義；不執行 Markdown 內嵌 HTML。
- cardSection：匹配第二層章節標題，容許「一、」等編號，擷取至下一個同層或更高層標題。
- parseWeeklyCard：第一層週報標題讀取日期；解析本週摘要中的編號／項目清單，保留縮排行的續行；若來源明確提供勾選標記才顯示完成狀態。
- cardTableCells / parseTrackingCard：依欄名定位，不寫死欄順序；支援現有四欄和規格六欄（含項目），辨識表頭分隔線及跳脫管線符號；缺表頭、缺項目、欄數錯誤會回報解析失敗。
- splitTrackingCard：無明確優先度時 5+其餘；有優先度時 P0/P1/未分類可見、P2 收合。
- fetchCardMarkdown：沿用 RAW 常數，以 fetch 取得文字、檢查 HTTP 狀態，15 秒逾時，cache: no-cache。
- loadWeeklyCard / renderTrackingItem / loadTrackingCard：渲染摘要、項目、分類（若有）、狀態、對象/執行人/決策人/時間（若有），更新計數與載入狀態。P0 紅色標示，其餘中性色。
- 新 toggle 使用與歷史清單相同的 display none/block 切換方式，額外更新 aria-expanded；既有 toggle 未更動。
- 每次開啟或重新整理頁面讀取來源；沒有背景輪詢。Raw CDN 更新可能仍有傳播延遲。

### 1. 本週摘要（目前 main 真實資料）

畫面保留每筆的完整原文描述，沒有 100% 或憑空新增的結論；可展開摘要並點擊完整週報。

### 2. 待追蹤事項（目前 main 真實資料）
計數：23 筆。初始可見：
1. 三張獨立 Table（能量登錄／補助／得標）實際資料量
2. 貼標與搜尋排序 DEMO
